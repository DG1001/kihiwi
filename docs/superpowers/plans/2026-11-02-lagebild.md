# Lagebild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kiwi beantwortet „Wie ist der Stand?“, „Was steht als Nächstes an?“, „Wo hakt es?“ und „Was kann ich vorzeigen?“ aus einem nachts erzeugten, gekennzeichneten Lagebild, und Korrekturen gehen per Stimme.

**Architecture:** Ein neues Modul `wissen/lagebild.py` sammelt deterministisch Eingaben (Statusdokumente aus dem Index, Commits, Protokolle, Vorzeigbares, Korrekturen), lässt das Modell daraus fünf Abschnitte mit Verweisen schreiben, prüft die Verweise im Code und legt das Ergebnis mit Datum unter `zustand/lagebild/` ab. Der Sprachdienst gibt dem Modell immer nur den Kern („Worum es geht“) und bei den vier Fragen zusätzlich den passenden Abschnitt; das ganze Lagebild steht auf der Bühne. Neue Absicht `LAGE` und vier Auslösewörter in `sprachdienst/absicht.py`.

**Tech Stack:** Python 3 (venv `.venv`), SQLite FTS5 (`wissen/index.db`), llama.cpp/vLLM über `sprachdienst/llm.py`, Git über `subprocess`, Belegungsstelle per HTTP (`127.0.0.1:8930`), Bash (`dienste.sh`), Browser-Client `sprachdienst/klient.html`.

**Spec:** `docs/superpowers/specs/2026-11-02-lagebild-design.md`

## Global Constraints

- Das Repo ist öffentlich: keine Namen von Projekten, Dateien oder Personen aus den Unterlagen in Code, Beispielen, Tests oder Commit-Nachrichten. Statusdokumente nur über die Konfiguration benennen.
- Code, Kommentare, Ausgaben und Doku auf Deutsch, Stil wie im übrigen Repo (Umlaute in Kommentaren ausgeschrieben: ae, oe, ue).
- Nichts verlässt das Netz außer dem `git pull` des Abgleichs. Nie an `0.0.0.0` oder `[::]` binden.
- `zustand/`, `wissen/lagebild.json` und `aufnahmen/` gehören nicht ins Repo.
- Das model-switch-Profil wird nicht geändert; der Lauf löst keinen Modellwechsel aus.
- Größen: ganzes Lagebild höchstens 10.000 Zeichen (≈ 2.500 Token), Kern höchstens 1.600 Zeichen (≈ 400 Token), ein Abschnitt höchstens 2.000 Zeichen (≈ 500 Token).
- Korrekturen gelten bis zur Ablösung durch eine neuere Quelle, höchstens 14 Tage.
- Automatisch erneuert wird nur nachts; auf Zuruf nur nach Ansage und Ja.
- Tests laufen als Modul mit `assert`, nicht mit pytest (das ist nicht installiert): `.venv/bin/python -m <paket>.<modul>_test`. Tests brauchen weder Modell noch echten Index.
- Prozesse über den Port finden, nicht über den Namen.
- Commit nach jeder Aufgabe; gepusht wird nur auf Zuruf.

## Review Focus

1. **Noch kein Lagebild** (erster Start, alle Läufe gescheitert): Die vier Fragen bekommen „Es gibt noch kein Lagebild …“ statt einer erfundenen Antwort; der Prompt bleibt wie heute. → Tests in Aufgabe 2 (`aktuell`/`prompt_block` ohne Dateien) und Aufgabe 6 (Gespräch).
2. **Modellausgabe kaputt** (Überschriften fett statt `##`, Verweis `[E99]`, gar keine Verweise): ungültige Punkte fallen weg, fehlende Abschnitte sagen „Keine Angaben in den Quellen“, bleibt nichts Gültiges übrig, gilt das alte Lagebild weiter. → Tests in Aufgabe 4.
3. **„Lagebildkorrektur“ ohne Inhalt:** Kiwi fragt nach („Was soll ich am Lagebild korrigieren?“) und legt nichts ab. → Tests in Aufgabe 1 (Thema leer) und Aufgabe 6.
4. **Belegungsstelle nicht erreichbar:** wie beim Modell-Wächter weiterarbeiten („nicht erreichbar heißt nicht verboten“), aber protokollieren. → Test in Aufgabe 5.
5. **Datumsgrenzen:** Korrektur genau 14 Tage alt, zwei Läufe am selben Tag (der jüngere gilt), Lagebild älter als zwei Tage (Kiwi nennt das Datum). → Tests in Aufgabe 2 (`lage_frage`).

### Task 4: Erzeugen, prüfen, ablegen

**Files:**
- Modify: `sprachdienst/llm.py` (`antwort_text` Z. 183, `_roh` Z. 199, `_strom` Z. 143: Parameter `timeout: int = 60` bis zu `_anfragen` durchreichen)

**Interfaces:**
- Consumes: `eingaben_sammeln`, `budget_einhalten`, `aktuell`, `offene_korrekturen`, `korrekturen_abloesen`
- Produces:
  - `llm.antwort_text(system, frage, max_tokens=400, temperatur=0.2, timeout: int = 60)`
  - `async erzeugen(eingaben: list[dict], vorher: str | None, fragen) -> str` — `fragen(system: str, nutzer: str) -> Awaitable[str]`, im Betrieb `lambda s, n: llm.antwort_text(s, n, max_tokens=3500, temperatur=0.2, timeout=900)`
  - `pruefen(roh: str, eingaben: list[dict], jetzt: datetime) -> tuple[str | None, dict[str, str], int]` — (fertiges Markdown oder `None`, Ablösungen `{"K1": "Titel, TT.MM.JJJJ"}`, Zahl entfernter Punkte)
  - `ablegen(text: str, eingaben: list[dict], entfernt: int, jetzt: datetime, verz) -> Path` — schreibt `<YYYY-MM-DD>T<HHMM>.md` und `.eingaben.json` (ID, Art, Titel, Datum; kein Text)
